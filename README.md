# Sutradhaar Newsroom Admin

Standalone Next.js admin panel for the Sutradhaar NestJS API.

## Development

```bash
cp .env.example .env.local
npm install
npm run dev
```

Open `http://localhost:3001`. The API must run at `http://localhost:4000/api/v1`.

Seeded development account: `admin@sutradhaarnews.com`. The local seed password is `ChangeMe123!`; change it before any shared or production deployment.
